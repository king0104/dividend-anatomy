# 01. 데이터 제공자 선정

## 배경

PROJECT.md 7장은 Finnhub를 주력 제공자로 선정했으나, 같은 장에 "무료 API 정책은
자주 바뀐다. 가입 후 실제 응답과 현재 약관을 직접 확인할 것"이라고 명시했다.
10장은 이를 "Day 1이 갈림길인 이유"로 못박는다:

> 주가 시계열을 무료로 못 받으면 기여도 분해가 불가능하고, 이 프로젝트의 정체성이 무너진다.

Day 1에 가정을 사실로 확정하기 위해 `check_finnhub_api.py`로 직접 검증했다.

- 실행: 사용자 로컬 환경에서 무료 플랜 토큰으로 직접 호출 (본 문서는 그 결과를 기록)

## 판단

PROJECT.md 11장 위험 요소 표의 "주가 시계열 무료 확보 실패" 위험이 실제로 발생했다.
배당 이력까지 함께 막혀 있어 예상보다 범위가 크다 — Finnhub 무료 플랜으로는
**핵심 기능(4.2 기여도 분해, 4.3 월별 현금흐름)에 필요한 원천 데이터를 확보할 수 없다.**

→ Finnhub는 재무 지표(`/stock/metric`) 보조 용도로만 유지.
→ 배당 이력과 주가 시계열은 대체 제공자를 확보해야 프로젝트를 계속 진행할 수 있다.

### 판단 — 새로운 갈림길

배당 이력과 분할 이력은 무료로 충분히 확보된다. 문제는 여전히 **주가 시계열**이다.

- PROJECT.md 5.1은 기여도 분해의 기준 시점을 "3년 전? 5년 전?"으로 열어두고 결정을
  요구하는데, Massive 무료 플랜은 **일별 종가를 최대 약 2년까지만** 준다.
- 403으로 막히는 Finnhub와 달리 Massive는 **에러 없이 조용히 자른다** — 요청한 기간과
  실제 응답 기간이 다르다는 걸 클라이언트가 직접 검증하지 않으면 놓친다.
  → PROJECT.md 5.4 "시계열 정합성 검증" 항목이 이 케이스를 반드시 잡아야 한다는
  실증 근거.

→ 배당 이력/분할 이력은 Massive로 확정.
→ 주가 시계열은 **기준 시점을 2년 전으로 낮추거나(기능 축소), 유료 플랜/제3의
  제공자를 추가로 검토**해야 한다. 어느 쪽이든 PROJECT.md 5.1의 기준 시점 결정에
  직접 영향을 준다.

## 2년 창으로 충분한가 — 실증 확인 (2026-08-22)

주가 하락에서 옴" 같은 사례는 하나도 나오지 않았다. 심지어 예시 종목 **MO 자체도

초반 주가 폭락기에서 나온 것으로, 2년보다 훨씬 긴 구간이 필요했다는 뜻이다.

→ 2년 구간은 "계산이 돌아간다"는 것만 보장할 뿐, **프로젝트의 핵심 메시지(경고
플래그가 필요한 사례)를 안정적으로 보여주기엔 부족**하다.
→ 3~5년 확보가 실질적인 가치가 있다고 판단. 대체 제공자 탐색을 계속 진행한다.

## 약관 재검토 — "무료로 오는가"와 "공개 배포해도 되는가"는 다른 질문

PROJECT.md 7장이 Finnhub를 주력으로 골랐던 핵심 이유 중 하나가 "개인·비상업 용도
명시 → 포트폴리오 배포가 이 범위에 부합"이었고, FMP는 정반대 이유("표시·재배포 시
별도 라이선스 계약 필요")로 제외됐다. 지금까지 Massive/Twelve Data 검증은 **API가
데이터를 주는가**만 확인했지, **그 데이터를 공개 웹사이트에 표시해도 되는가**는
확인하지 않았다. 웹 검색 + 공식 약관 페이지로 확인한 결과:

### Twelve Data — 문제 확인됨

- 공식 약관(twelvedata.com/terms) 2.3(l): 무료(Free Tier) 데이터는 상업적 목적
  사용 금지
- 2.4조: 재배포(redistribution)나 외부 공개 표시(external display)는 특정 유료
  Subscription Tier / Data Add-on에서만 허용
- 지원 문서(Commercial and personal usage): 무료 플랜은 "strictly for personal
  or internal use"이며, **포트폴리오 웹사이트에 주가 차트나 배당 이력을 공개
  표시하는 것은 허용되지 않는다**고 명시
→ **FMP와 같은 사유로 걸린다.** 무료 플랜으로 받은 주가 시계열은 공개 배포용으로
  쓸 수 없다고 봐야 한다.

### Massive(구 Polygon.io) — 불명확, 확정 못 함

- 약관(massive.com/legal/individuals-terms-of-service)은 "personal, non-commercial,
  and non-business purposes" 사용만 허용한다고 명시하지만, 공개 웹사이트 표시나
  재배포를 명시적으로 허용/금지하는 조항을 자동 파싱으로는 찾지 못했다
- Finnhub처럼 "포트폴리오 배포가 이 범위에 부합"이라고 명확히 말하는 문구는 없었다
- **법적 문제라 추측으로 결론 내리지 않는다.** support@massive.com에 직접 문의해
  서면 확인이 필요한 상태로 남겨둔다

### 영향

- Twelve Data를 주가 시계열 소스로 그대로 쓰면, 이 프로젝트가 FMP를 제외했던 논리와
  스스로 모순된다. **주가 시계열 제공자를 재검토해야 한다.**
- Massive도 배당/분할 이력에 대해 같은 확인이 안 끝난 상태다.

## Stooq 검증 — ToS 이전에 접근 자체가 막힘

Stooq(무료, API 키 불필요, CSV 다운로드)를 대체 후보로 검토했으나, ToS 문구를
찾기도 전에 더 근본적인 문제가 나왔다.

`curl`로 홈페이지(`stooq.com`)와 실제 CSV 다운로드 엔드포인트
(`/q/d/l/?s=ko.us&i=d`) 둘 다 직접 요청한 결과, 데이터 대신 아래 응답이 왔다:

```
This site requires JavaScript to verify your browser. Please enable JavaScript and reload.
```

브라우저에서 SHA-256 proof-of-work 연산을 풀어야 통과되는 **봇 차단 챌린지**가
걸려 있다 (홈페이지·CSV 엔드포인트 동일하게 적용됨).

### 판단

이건 "재배포 약관이 애매하다"는 회색지대 문제가 아니라 **"자동화된 접근 자체를
명시적으로 차단해뒀다"**는 훨씬 명확한 신호다. 이 챌린지를 우회해서 하루 1회
배치로 긁으면 재배포 조항 위반보다 훨씬 분명하게 "접근 통제 회피"에 해당한다.
ToS 원문을 확인할 필요도 없이 **실무적으로 배치 스크립트로 쓸 수 없다.**

→ **Stooq 제외.**

## Alpha Vantage 재검토 (2026-08-22)

PROJECT.md 7장은 Alpha Vantage를 "무료 하루 25콜로 부족"이라는 사유만으로
제외했다. 이는 "57종목 매일 갱신" 전제였을 뿐, 재배포 약관은 애초에 확인한 적이
없었다. 두 가지를 다시 확인했다.

### 1) 재배포/공개 표시 약관 — 원문 확인 (alphavantage.co/terms_of_service/)

핵심은 2조(Grant of License)의 "commercial use" 정의다. 아래 넷 중 하나라도
해당하면 상업적 사용으로 간주되어 무료 라이선스(개인/비상업 전용) 밖으로
나간다:

> i. 개인적 사용을 넘어서는 목적(문구가 다소 모호하게 "individual in nature"
>    활동까지 예시로 나열되어 있어 해석 여지가 있음)
> ii. 법인/단체 명의로 사용 (개인이 아닌 경우) — **해당 없음**
> iii. "제3자가 정보에 접근할 수 있게 하는 **상업적 활동(commercial activity)**의
>      일부로 사용" — **핵심 조항**
> iv. 금융업계(투자자문·증권사 등) 종사자/제휴 — **해당 없음**

Twelve Data는 무료 플랜의 "재배포·외부 표시"를 상업성과 무관하게 유료 전용으로
막아뒀던 반면, Alpha Vantage의 (iii)은 **"상업적 활동"이 전제조건**이고 그 안에서
"제3자 접근을 허용하는지"를 본다. 돈을 받지 않는 개인 포트폴리오는 애초에
"상업적 활동"이 아니므로, 이 조항 구조상 (i)의 모호함만 해소되면 통과할
가능성이 지금까지 확인한 제공자 중 가장 높다.

→ 완전히 확정된 건 아니다. (i)의 모호한 문구 때문에 서면 확인이 여전히 필요.

### 2) 요청 제한 — 오픈소스 프로젝트는 우회 가능

- 무료 플랜: 하루 25건 (분당 제한은 문서에 명시 안 됨)
- **"verified open-source or educational projects"는 무제한 요청 허용** —
  `support@alphavantage.co` 문의로 신청
- 이 프로젝트는 공개 GitHub 저장소(포트폴리오 목적)이므로 이 프로그램의
  대상에 해당할 가능성이 높다. 승인되면 PROJECT.md가 애초에 Alpha Vantage를
  제외했던 사유(57종목 매일 갱신 불가) 자체가 사라진다.

### 판단

Alpha Vantage가 현재까지 검증한 제공자 중 **가장 유망한 후보**로 올라섰다.
단, (i) 조항의 모호함과 오픈소스 프로그램 승인 여부는 실제 서면 확인이
필요하다. Massive 문의와 같이 진행한다.
